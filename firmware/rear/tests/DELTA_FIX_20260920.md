# ΔP 최종 배분 수정 — 2026-09-20

수정 소스: `Core/Src/torque_vectoring.c`.

페달 감소 직후 슬루 상태가 새로운 ΔP 상한을 초과해 한쪽 명령이 0이 되는 문제를 수정했다. TV와 ED 모두 슬루 적용 이후 최신 요구량의 70%와 모터 가용 범위를 만족하도록 최종 ΔP를 제한한다. TV는 속도별 구동력 상한도 다시 확인한다. 요구 총량이 양쪽 모터 가용 전력 합계를 초과하면 총량부터 제한한다.

이후 좌우 명령을 계산하므로 모터 상한에서 차동을 유지하려고 반대편 출력까지 추가로 줄이는 처리를 제거했다. `tv->delta_power`와 다음 슬루 상태에는 최종 `power_right-power_left`를 사용한다. 페달 해제/ED 금지 시 ED 필터 상태를 초기화하고 차동 모드가 모두 비활성이면 최종 ΔP는 0이다.

PID(50/1/5), ΔP 절대 상한(4.5kW), 요구량 비율(0.7), IMU yaw 부호(+1), 조향 교정은 변경하지 않았다. +X 전방/+Y 좌측/+Z 위의 사용자 확인 장착 방향에 따라 좌회전 yaw가 양수다. 부호를 화면상 추종 모양만으로 바꾸지 않는다. 목표와 측정값이 같은 방향으로 움직이는 것과 정확히 추종하는 것은 별개다.
